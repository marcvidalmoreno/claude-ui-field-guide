## Why this exists

It started with a small annoyance: Claude answered almost only in text, so every reply had to be typed, even a plain “y” or “n”. A yes/no question could have been two buttons, the recommended one more prominent. File names came without links. Commands had to be copied into a terminal somewhere else. Looking for better options turned up a whole set of buttons, cards, panes and links Claude can use instead, and this catalog collects them.

The idea behind it: **technology out of sight**. An AI tool should spend its power on saving people steps and keep the machinery invisible.

## The principle: reply cost

When Claude needs something from you, it should use the control that costs you the least effort and attention. From cheapest to most expensive:

1. **Nothing.** Claude decides (when the choice is low-risk and reversible) and says what it assumed.
2. **One click.** A button that answers or acts: [next-step box](/under-message/nextstep/), [question card](/chat/question/), [plan approval](/under-message/plan/).
3. **One click to open.** A link to the file, [pane](/panes/panes/), session or page.
4. **A Run button** on a command, or a [terminal tab](/panes/terminal/) Claude runs it in.
5. **A block to copy** and paste somewhere else.
6. **A typed reply**, only for open questions.
